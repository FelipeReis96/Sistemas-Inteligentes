# Sistemas Inteligentes - Entrega 1

Implementação do Problema do Caixeiro Viajante com Têmpera Simulada e
Algoritmo Genético. Os dois métodos usam a mesma representação de rota e a
mesma função de custo.

O artigo final está em `entrega1/artigo.pdf`. O código-fonte está em
`entrega1/src/` e usa apenas a biblioteca padrão do Python.

## Execução

```sh
python3 entrega1/src/main.py --algorithm tempera --cities 40
python3 entrega1/src/main.py --algorithm ag --cities 40
```
